# Polygon Art Generator – Turtle Graphics

This program creates generative polygon artwork using Python’s **turtle graphics** library.  
The user can choose from **nine different art presets**, each producing a unique pattern made from triangles, squares, pentagons, or mixed polygons.

Every piece of art is generated using random colors, rotations, positions, and sizes — making each run visually unique.

---

## Features

- Draws polygons with **3**, **4**, or **5** sides
- Fully randomized color, orientation, border width, and size
- Produces both **single-layer** and **multi-layer nested** patterns
- Includes **9 different art modes** matching assignment requirements
- Uses only Python’s built-in modules (no installation needed)

---

## Art Modes (1–9)

| Mode | Description |
|------|-------------|
| **1. Triangles** | Random single-layer triangles |
| **2. Squares** | Random single-layer squares |
| **3. Pentagons** | Random single-layer pentagons |
| **4. Mixed Polygons** | Mix of 3–5 sided polygons |
| **5. Nested Triangles** | 3–5 shrinking layers with rotation |
| **6. Nested Squares** | 4–6 layered squares with rotation |
| **7. Nested Pentagons** | 4–6 layered pentagons |
| **8. Mixed Nested Polygons** | Mixed nested shapes (3–5 sides) |
| **9. Free Mixed Pattern** | Mixed shapes without nesting |

---

## How to Run

1. Ensure you have **Python 3** installed.  
2. Save the script as: polygon_art.py
3. Run the program using: python3 polygon_art.py
4. Choose a mode (1–9) to generate an artwork.
